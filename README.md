# TERMINAL DEFENDER 2.0
> **Mathematical Defense Protocol**

An arcade-style cyberpunk mathematical defense game built with zero external dependencies (pure Vanilla JS, HTML5 Canvas 2D, WebAudio synthesizer, and CSS3).

---

## 🎮 Gameplay & Features

- **Procedural Mathematical Combat**: Solve procedurally generated math problems to charge and fire your defense laser. 5 distinct difficulty tiers ranging from basic arithmetic to algebraic order of operations, square roots, and powers.
- **Dynamic Wave Director**: 10 escalating campaign waves featuring 8 enemy spider variants (basic, speed, armored, split, shield, phantom, elite) plus multi-phase boss battles (The Calculator, Fractal Weaver, Prime Devourer, Null Mother, and Terminal Overlord).
- **Hidden Wave 11**: Clear the defense protocol to unlock **The Deep Terminal** and face the Corrupted Kernel.
- **Pure WebAudio Synthesis**: 100% procedurally synthesized SFX and an interactive multi-mode music sequencer (menu, wave, boss, deep terminal modes + low-HP danger alarm).
- **VFX Engine**: Object-pooled particle systems, beam lasers, shockwaves, glitch distortions, and trauma-based screen shake.
- **Persistence**: High scores, accuracy records, lifetime statistics, 12 unlockable achievements, and top-10 leaderboard stored locally.
- **Accessibility & Touch Support**: High contrast mode, reduced motion, colorblind mode, text scaling, and an on-screen touch numpad for mobile devices.

---

## 🕹️ Controls

- **0 - 9**: Input numerical answer
- **ENTER**: Fire laser / select menu option
- **BACKSPACE**: Delete last character
- **TAB**: Cycle target lock
- **ESC**: Pause / Resume / Back
- **M**: Toggle audio mute
- **Mouse / Touch**: On-screen buttons and touch numpad for mobile play

---

## 🚀 Deployment

Built as a static web application:
- Open `index.html` in any modern web browser to play locally.
- Ready for immediate zero-config deployment to [Vercel](https://vercel.com), GitHub Pages, or Netlify.
